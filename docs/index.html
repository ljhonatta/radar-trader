Legenda

Exportar

No celular, abre a tela de compartilhar com todas as imagens juntas: escolha Salvar imagens para ir para a galeria. Se o seu aparelho não oferecer essa opção, use o ZIP.

O download sai exatamente como a prévia. As imagens ficam prontas na memória: baixar de novo não refaz o trabalho enquanto você não mexer no carrossel.

Perfis

Cada perfil guarda nome, @, cor padrão, logo, foto e ícone. No Editor, você escolhe de qual perfil vai publicar e tudo entra sozinho no carrossel.

Inteligência artificial (OpenAI)

Usada para reescrever o carrossel e a legenda, regenerar slides e ler as imagens que você envia. A chave fica guardada só neste navegador, nunca vai para o GitHub. Em outro celular ou computador, coloque de novo. Sem chave, o carrossel é montado com os dados da ficha da notícia.

Perfis, carrosséis e imagens que você mudar aqui ficam neste navegador. A coleta de notícias usa a chave guardada no GitHub (Settings → Secrets).
